# Paola Galvão Studio

Sistema web desenvolvido no Projeto Integrador II da UNIVESP para apoiar a organização e a gestão do Paola Galvão Studio.

**Em desenvolvimento — primeira versão Beta funcional.** Esta etapa é dedicada aos testes e à validação com a cliente, com ajustes antes da entrega final.

A área pública apresenta o estúdio, os serviços e o agendamento online, com integração com o WhatsApp para avaliações prévias. O painel administrativo reúne agenda, clientes, histórico, retornos, serviços e caixa.
